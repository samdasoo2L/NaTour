# 이미지 에셋 안내

현재 SVG 파일은 웹 레이아웃 확인용 목업 일러스트이며 실제 장소·식당·메뉴·상품 사진이 아닙니다.

## 교체 방법

1. 실제 사진을 같은 폴더에 넣습니다.
2. `data.js`의 `photo` 또는 메뉴/물품의 `photo` 경로를 새 파일 경로로 바꿉니다. 또는 기존 SVG를 같은 파일명으로 교체할 수도 있습니다.
3. 이미지 파일명은 영문 소문자와 하이픈을 권장합니다. GitHub Pages에서는 대소문자가 구분됩니다.

## 폴더

- `cover/`: 첫 화면 여행 대표 이미지
- `restaurants/`: 식당 대표 사진
- `menus/`: 메뉴 사진
- `shopping/`: 시장·매장 대표 사진과 추천 물품 사진
- `attractions/`: 관광지 메인 사진
